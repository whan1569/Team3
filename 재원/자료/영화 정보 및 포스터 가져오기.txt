영화 정보 및 포스터 가져오기

1. 영화진흥위원회 KOBIS API 활용
KOBIS API를 사용하여 박스오피스 순위와 기본적인 영화 정보를 가져올 수 있습니다.
- https://github.com/Builter251/KOBOP
- https://dkss7413.tistory.com/21
이 API에서는 영화 제목, 개봉일, 관객 수 등의 정보를 제공합니다.

2. KMDB(한국영화데이터베이스) API 활용
KMDB API를 사용하여 더 상세한 영화 정보와 포스터 이미지를 가져올 수 있습니다.
- https://github.com/Builter251/KOBOP
- https://youtaek123.tistory.com/34
이 API에서는 영화 줄거리, 감독, 배우, 포스터 URL 등 더 풍부한 정보를 제공합니다.

* KMDb OPEN API 이용하기
- https://velog.io/@han0707/KMDb-OPEN-API-%EC%9D%B4%EC%9A%A9%ED%95%98%EA%B8%B0-1


3. 두 API 조합하기
KOBIS API로 박스오피스 순위와 기본 정보를 가져옵니다.
가져온 영화 제목을 사용하여 KMDB API에서 상세 정보와 포스터를 검색합니다34.
구현 방법

API 키 발급: KOBIS와 KMDB에서 각각 API 키를 발급받습니다4.

API 호출:
================================================================================
// KOBIS API 호출 예시
$.ajax({
  url: 'http://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json',
  data: { key: 'YOUR_KOBIS_API_KEY', targetDt: 'YYYYMMDD' },
  success: function(result) {
    // 박스오피스 정보 처리
  }
});

// KMDB API 호출 예시
$.ajax({
  url: 'http://api.koreafilm.or.kr/openapi-data2/wisenut/search_api/search_json2.jsp',
  data: { collection: 'kmdb_new2', ServiceKey: 'YOUR_KMDB_API_KEY', query: '영화제목' },
  success: function(result) {
    // 상세 정보 및 포스터 URL 처리
  }
});
================================================================================

HTML과 CSS를 사용하여 영화 정보와 포스터를 표시합니다.

예외 처리:
포스터 이미지가 없는 경우 기본 이미지를 표시하는 등의 예외 처리를 구현합니다.


주의사항
API 호출 횟수에 제한이 있을 수 있으므로, 캐싱을 고려하세요.
KMDB API의 경우, 포스터 URL이 'posters' 필드에 있을 수 있으니 주의하세요.
크로스 오리진 이슈를 해결하기 위해 서버 사이드 프록시를 사용하거나 CORS 설정을 확인하세요.
이러한 방법을 통해 넷플릭스와 유사한 영화 정보 페이지를 구현할 수 있습니다. API를 효율적으로 사용하고 사용자 경험을 고려하여 디자인하면 좋은 결과를 얻을 수 있을 것입니다.
