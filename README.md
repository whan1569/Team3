# Team3

[Team3_web](https://github.com/whan1569/Team3_web) 프로젝트 구현 이전 단계에서 작성한 기획, 회의, 역할 분담, 일정 관리 산출물을 정리한 팀 프로젝트 아카이브입니다.

이 저장소는 실행 가능한 서비스 코드 저장소라기보다, 팀 프로젝트를 시작하기 전 아이디어를 정리하고, 작업 범위를 나누고, 일정과 역할을 관리하기 위해 사용한 협업 기록 저장소입니다.

실제 구현 결과물은 별도 저장소인 [Team3_web](https://github.com/whan1569/Team3_web)에서 관리합니다.

## Purpose

이 저장소의 목적은 팀 프로젝트 진행 과정에서 발생한 기획 및 협업 기록을 보관하는 것입니다.

주요 기록 대상은 다음과 같습니다.

- 프로젝트 초기 아이디어 정리
- 회의 내용 기록
- 역할 분담 및 작업 범위 정리
- WBS 기반 일정 관리
- 프로젝트 계획서 작성
- 팀원별 조사 및 준비 자료 보관
- 실제 구현 저장소인 [Team3_web](https://github.com/whan1569/Team3_web)으로 넘어가기 전의 사전 작업 기록

## Repository Type

| Type | Description |
|---|---|
| Planning Archive | 프로젝트 구현 전 기획 자료 보관 |
| Meeting Notes | 회의 내용 및 논의 사항 기록 |
| WBS / Schedule | 작업 분배와 일정 관리 |
| Team Collaboration | 팀원별 자료와 역할 분담 기록 |
| Pre-development Docs | 실제 개발 이전 단계의 문서화 자료 |
