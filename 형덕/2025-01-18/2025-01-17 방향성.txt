데이터 준비 단계
사용자-장르 데이터 전처리

사용한 방법: MultiLabelBinarizer
사용 이유:
장르 데이터를 벡터화하여 사용자 간 유사성을 계산하기 위한 기반 마련.
다중 레이블 데이터를 이진 벡터로 변환하여 각 사용자의 장르 선호도를 수치화.
사용자-영화 매트릭스 생성

사용한 방법: csr_matrix (희소 행렬 생성)
사용 이유:
사용자-영화 간 데이터는 매우 희소하기 때문에 메모리 효율성을 위해 사용.
대규모 데이터 처리 및 연산 속도 향상을 위해 희소 행렬 사용.
행렬 분해 (Matrix Factorization)
사용된 기법: Truncated SVD (Singular Value Decomposition)
사용 이유:
고차원 데이터를 저차원으로 축소해 계산 효율성 증대.
사용자와 장르 간의 숨겨진 패턴(잠재 요인)을 학습.
데이터의 노이즈를 제거하고 중요한 정보만 남김.
결과:
각 사용자의 장르 선호도를 잠재 벡터(14차원)로 표현.
협업 필터링 (Collaborative Filtering)
사용된 기법: 사용자 기반 협업 필터링 (User-Based Collaborative Filtering)
사용 방법:
cosine_similarity를 사용하여 검색 사용자와 다른 사용자 간의 유사도 계산.
사용 이유:
사용자 간의 상호작용 데이터를 활용해 개인화된 추천 생성.
코사인 유사도를 사용해 벡터 방향성을 기준으로 패턴 비교.
장점:
절대적인 시청량보다는 영화 시청 패턴에 중점을 둠.
추천 알고리즘
사용된 기법: K-Nearest Neighbors (KNN)
사용 방법:
코사인 유사도를 기반으로 상위 20명의 유사 사용자를 탐색.
사용 이유:
검색 사용자와 가장 유사한 사용자의 시청 기록을 기반으로 추천.
연산 효율성이 뛰어나고, 대규모 데이터에서도 성능 유지.
영화 추천 로직
검색 사용자와 유사한 상위 20명의 사용자 추출.
유사 사용자가 본 영화 중 검색 사용자가 보지 않은 영화 추천.
최대 20개 영화 추천으로 과도한 결과 제한.
알고리즘 선택의 이유
SVD (행렬 분해):
사용자-장르 간 관계를 잠재 공간으로 압축해 효율적 계산 가능.
Cosine Similarity:
사용자 간 패턴 유사성을 평가해 정확한 유사도 계산.
KNN:
상위 유사 사용자를 선택해 개인화된 추천 제공.
협업 필터링:
사용자-영화 상호작용 데이터를 활용해 콘텐츠 메타데이터 없이도 추천 가능.



결론
목표:
검색 사용자가 보지 않은 영화를 추천.
사용자-영화 데이터와 사용자-장르 선호도를 결합해 개인화된 추천 제공.
결과:
검색 사용자와 유사한 상위 20명의 사용자가 본 영화 중 검색 사용자가 보지 않은 영화 추천.
장점:
개인화된 추천 제공 및 대규모 데이터 처리 가능.
단점:
Cold Start 문제: 새로운 사용자의 초기 추천이 어려움.
