1. 콘텐츠 기반 필터링 (Content-Based Filtering)
설명: 
-콘텐츠 자체의 특징(장르, 배우, 감독 등)을 기반으로 사용자가 이전에 좋아했던 콘텐츠와 유사한 콘텐츠를 추천.
-각 콘텐츠는 특징 벡터로 표현되며, 사용자가 선호하는 콘텐츠 벡터와의 유사성을 계산.
장점:
-개인화 수준이 높고, 사용자의 선호도 변화에 빠르게 반응.
-새로운 사용자가 기존에 평가한 콘텐츠만 있으면 추천 가능.
단점:
-콘텐츠 정보가 충분하지 않으면 추천 품질이 낮음 (콜드 스타트 문제).
-다양성이 부족하며, 사용자가 본 콘텐츠와 유사한 콘텐츠만 추천.
예시:
-사용자가 SF 장르를 선호하면, 유사한 SF 영화를 추천.

2. 협업 필터링 (Collaborative Filtering)
a. 사용자 기반 협업 필터링 (User-Based Collaborative Filtering)
사용자가 다른 사용자들과의 유사성에 따라 콘텐츠를 추천받는 방식.
예: 사용자가 A가 본 콘텐츠 중에서 다른 유사한 사용자 B가 좋아한 콘텐츠를 추천.
b. 아이템 기반 협업 필터링 (Item-Based Collaborative Filtering)
사용자가 이전에 좋아한 콘텐츠와 유사한 콘텐츠를 추천.
예: 사용자가 영화 A를 좋아했다면, 영화 A와 유사한 다른 콘텐츠를 추천.
장점:
-사용자와 콘텐츠 특징이 없어도 작동 가능.
-다양한 콘텐츠 추천 가능.
단점:
-새로운 사용자 또는 콘텐츠에 대한 정보가 부족하면 추천 어려움 (콜드 스타트 문제).
-데이터 양이 많아질수록 계산 비용 증가.
예시:
-사용자가 본 영화와 비슷한 평점을 준 사용자들이 본 다른 영화를 추천.

3. 하이브리드 필터링 (Hybrid Filtering)
설명:
-콘텐츠 기반 필터링과 협업 필터링을 결합한 방식.
-두 알고리즘의 단점을 보완하고, 더 높은 추천 품질을 제공.
장점:
-다양성과 개인화 수준이 모두 향상.
-콜드 스타트 문제를 일부 해결.
단점:
-구현이 복잡하고 계산 비용 증가.
예시:
-사용자와 유사한 사람들이 좋아한 콘텐츠를 기반으로 하면서, 사용자가 선호하는 콘텐츠와 유사한 콘텐츠를 함께 추천.

4. 지식 기반 추천 (Knowledge-Based Recommendation)<<<<<<<<<<(X)
설명:
-사용자 입력(예: "로맨틱 코미디 추천")이나 명시적 요구 사항에 따라 콘텐츠를 추천.
-사용자 선호와 콘텐츠 속성 간의 규칙 기반 매칭.
장점:
-명확한 규칙 기반 추천으로 설명 가능성이 높음.
-초기 사용자에게도 적용 가능.
단점:
-복잡한 규칙 설정 필요.
-개인화가 어려움.
예시:
-"액션 장르, 2시간 이하, 2010년 이후 개봉한 영화" 추천.

5. 그래프 기반 추천 (Graph-Based Recommendation)<<<<<<<<<<<<<<(X)
설명:
-사용자와 콘텐츠를 그래프 형태로 표현하여 연결 관계를 통해 추천.
-사용자-콘텐츠, 콘텐츠-콘텐츠 간 관계를 탐색.
장점:
-복잡한 연관 관계를 분석 가능.
-데이터 연결을 활용해 다양한 추천 가능.
단점:
-대규모 데이터에서 계산 비용이 높음.
예시:
-사용자가 본 영화의 배우가 출연한 다른 영화를 추천.

6. 딥러닝 기반 추천 (Deep Learning-Based Recommendation)
설명:
-딥러닝 모델(CNN, RNN, AutoEncoder 등)을 활용하여 사용자 행동, 콘텐츠 속성, 시청 패턴 등을 학습.
-사용자 행동 데이터를 임베딩 벡터로 변환하여 유사도를 계산.
장점:
-대규모 데이터에서 높은 성능 발휘.
-복잡한 상관관계 분석 가능.
단점:
-데이터와 계산 리소스가 많이 필요.
-결과 해석이 어렵고 구현 복잡.
예시:
-사용자의 시청 패턴(시간, 장르 선호 등)을 학습하여 개인화된 추천 제공.

7. 강화 학습 기반 추천 (Reinforcement Learning-Based Recommendation)
설명:
-사용자 행동(클릭, 시청 등)에 따라 실시간으로 보상을 계산하며 추천 알고리즘을 학습.
-추천 후 사용자 반응(예: 시청 여부)을 바탕으로 학습.
장점:
-실시간 적응 가능.
-추천 품질을 지속적으로 개선.
단점:
-초기 데이터 부족 시 성능이 낮음.
-학습 과정이 복잡.
예시:
-사용자가 클릭한 콘텐츠와 비슷한 콘텐츠를 실시간으로 업데이트하여 추천.

8. 연관 규칙 기반 추천 (Association Rule-Based Recommendation)
설명:
-"A를 본 사용자는 B도 본다"는 연관성을 분석하여 추천.
-주로 Apriori 알고리즘이나 FP-Growth 알고리즘 사용.
장점:
-단순하고 빠른 계산.
-명확한 규칙 제공.
단점:
-복잡한 데이터에서는 추천 품질이 떨어질 수 있음.
예시:
-사용자가 액션 영화 A를 본 경우, 다른 사용자가 A와 함께 본 영화 B 추천.
