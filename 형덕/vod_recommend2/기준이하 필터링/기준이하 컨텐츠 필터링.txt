1. 데이터 분류 및 기준 구간 설정

목표: 데이터를 "짧게 보고 다시 안 본 사람"과 "짧게 보고 다시 본 사람"으로 나누어 비교하고, 일정 기준 이상인 구간에서 "본 것으로 간주"할 데이터를 도출 

방법: 1분(060초), 2분(61120초), 3분(121~180초) 등 시청 시간을 구간별로 나눕니다.
각 구간에서 다시 본 사람(Resumed)과다시 안 본 사람(Not Resumed)의 비율을 계산합니다.

2. 비교 기준 데이터 계산

데이터 분석

1) 1분~5분 데이터 분석:
각 구간에서 다시 본 사람(Resumed)의 비율이 증가하는 패턴을 시각화합니다.
다시 본 사람 비율이 특정 시청 시간(예: 3분 이상)부터 안정적으로 증가하거나 유지되는 경우, 해당 값을 "본 것으로 간주"하는 기준으로 설정.
추가 데이터 비교

2) 다른 시간대 데이터 합산:
1분~5분뿐만 아니라 6분 이상 데이터를 합산하여 분석합니다.
추가 데이터를 통해 특정 시간 이상 시청자가 계속 증가하는 패턴을 확인합니다.
구체적인 계산
각 구간별 다시 본 사람 비율 = (구간에서 다시 본 사용자 수) / (구간에서 전체 사용자 수)
특정 비율(예: 50%, 70%) 이상의 구간부터 **"충분히 본 사람"**으로 정의.

3. 히스토그램과 스택형 막대 그래프를 활용하여 아래 내용을 시각화:

1) 구간별 Resumed/Not Resumed 비율.
특정 구간 이상에서 Resumed 비율이 명확히 증가하는 패턴.

2) Not Resumed(단일 시청자)의 안정적으로 증가하거나 유지되는 구간 도출.

4. 설득력 있는 기준 도출
데이터 기반의 결정:
예를 들어, Resumed/Not Resumed 비율이 안정적인 구간과 watch ration가 안정적인 구간의 평균값을 "본 것으로 간주"한다고 정의.

콘텐츠 이해를 위한 최소 시간:
Netflix 콘텐츠는 대개 길이가 긴 드라마, 영화로 구성. 2분은 줄거리나 분위기를 파악할 수 있는 최소 시간.
사용자 행동 분석:
Netflix는 A/B 테스트와 데이터 분석을 통해 사용자가 2분 이상 시청했을 때 콘텐츠를 계속 소비할 가능성이 높은 것을 발견.
전환율 관점:
2분 이상 시청은 사용자가 콘텐츠에 몰입할 가능성을 나타내며, 이를 '유의미한 시청'으로 간주.
구독자 유지 관리:
시청 기록은 개인화 추천 알고리즘의 기초 자료로 사용. 2분 이상의 시청이 데이터 활용에 충분한 임계점으로 설정.
