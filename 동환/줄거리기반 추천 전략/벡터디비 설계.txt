### 최종 벡터 데이터베이스 설계

1. **저장될 데이터 및 파일 구조**

- **파일 형식**: SQLite 파일 (예: chroma.sqlite3)
- **저장 위치**: chromadb_data/
- **저장되는 주요 데이터**:
  1. **asset_id**: 영화 고유 ID (기존 컬럼명 유지) - 각 벡터를 고유하게 식별하기 위해 필수.
  2. **vector**: 벡터화된 임베딩 (768차원 벡터)
  3. **metadata**: 영화와 관련된 메타데이터
     - **asset_nm**: 영화 제목
     - **genre**: 영화 장르
     - **rlse_year**: 출시 연도
     - **director**: 감독
     - **actr_disp**: 주요 출연진
     - **rate**: 연령 등급
     - **orgnl_cntry**: 제작 국가

2. **컬럼 명 변경 사항**

기존 vod_movie 테이블에서 필요한 컬럼을 벡터 데이터베이스에 저장할 때 몇 가지 변경 사항이 있습니다.

| **기존 컬럼명**   | **새로운 데이터베이스 컬럼명**     |
|-------------------|-----------------------------------|
| asset_id          | asset_id (변경 없음, 필수 항목)  |
| smry              | vector (벡터화된 임베딩으로 변환) |
| asset_nm          | asset_nm                          |
| genre             | genre                             |
| rlse_year         | rlse_year                         |
| director          | director                          |
| actr_disp         | actr_disp                         |
| rate              | rate                              |
| orgnl_cntry       | orgnl_cntry                       |

3. **데이터 저장 프로세스**

1. **텍스트 통합**:
   - 줄거리(smry), 감독(director), 출연진(actr_disp)을 통합하여 하나의 텍스트로 생성.
   - 예: "줄거리: {smry} 감독: {director} 출연진: {actr_disp}"

2. **벡터화**:
   - Sentence-BERT 모델을 사용하여 위의 통합 텍스트를 벡터화하고, 768차원의 임베딩을 생성.

3. **데이터베이스 삽입**:
   - 벡터화된 데이터는 ChromaDB에 저장됩니다.
   - 저장 형식:
     - **asset_id**: 영화 고유 ID (필수 항목)
     - **vector**: 768차원 벡터
     - **metadata**:
       - asset_nm: 영화 제목
       - genre: 영화 장르
       - rlse_year: 출시 연도
       - director: 감독
       - actr_disp: 주요 출연진
       - rate: 연령 등급
       - orgnl_cntry: 제작 국가

4. **쿼리 및 검색 프로세스**

- 사용자 입력(영화 제목 또는 특정 영화 선택)을 벡터화하고, 벡터화된 데이터를 사용하여 ChromaDB에서 가장 유사한 벡터를 검색합니다.
- 검색된 결과에는 유사한 영화의 asset_id와 관련된 metadata(제목, 장르, 감독 등)를 반환합니다.

5. **최종 파일 저장 구조**

ChromaDB의 데이터는 SQLite 파일에 저장되며, 이 파일은 로컬 환경에서 사용될 수 있습니다. 데이터베이스 내에는 두 가지 주요 테이블이 생성됩니다:

1. **벡터 테이블**:
   - asset_id: 고유 ID (필수)
   - vector: 768차원 벡터 데이터
   - metadata: 각 영화에 대한 메타데이터

2. **검색 테이블**:
   - asset_id: 고유 ID (필수)
   - 유사도 점수: 쿼리 결과와의 유사도 점수
