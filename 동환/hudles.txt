1. 로컬 환경의 DB 용량 부족 문제  
   - 로컬 스토리지 한계를 극복하기 위해, 192.168.0.105 및 192.168.0.115 서버의 방화벽을 조정하여 추가적인 데이터 저장 용량을 확보함. 이를 통해 확장 가능한 분산 환경을 구축.  

2. 대용량 DB 컬럼으로 인한 서버 쿼리 지연  
   - 복잡한 테이블 구조로 인해 쿼리 실행 시간이 증가하는 문제를 해결하기 위해, 데이터를 시간 및 유형별로 분할하여 병렬 처리할 수 있도록 설계. 이를 통해 1초 내외의 응답 속도를 유지하도록 최적화.  

3. 전처리 과정에서 발생하는 높은 연산 부하  
   - 데이터 전처리 시 방대한 연산량으로 인해 지연이 발생하는 문제를 해결하기 위해, 멀티프로세싱이 가능한 전용 객체를 설계하여 병렬 처리 지원. 시스템 자원에 맞춰 적절한 프로세스 수를 조정하여 성능을 극대화.  

4. 벡터 DB 구축 후 데이터 정상 저 장 여부 검증 필요 
   - 벡터 DB 구축 이후 데이터가 올바르게 저장되었는지 확인하기 위해 디코딩 과정을 수행. 이를 통해 데이터가 정상적으로 입력 및 검색되는지 검증하고, 인덱싱 및 검색 결과의 정확성을 점검함.
